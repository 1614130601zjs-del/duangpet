# 小小桌宠（Little Pet）

独立的 SillyTavern 扩展。悬浮球打开编辑面板，上传角色图、涂抹互动选区，再把桌宠放出到独立悬浮窗中直接触摸互动。

## 功能

- 可拖动并吸附屏幕左右边缘的悬浮球。
- 上传 PNG、WebP、JPG 作为桌宠本体。
- 图片和互动选区保存在浏览器 IndexedDB，本地持久化，不写入聊天记录。
- 选区编辑支持涂抹、擦除、清空，柔边笔刷可调整大小。
- 只有涂抹进选区的部分会参与局部形变；选区外保持不动。
- 桌宠可放出到独立透明悬浮窗，拖动顶部把手调整位置，触摸角色进行互动。
- WebGL 网格形变与弹簧阻尼回弹。
- 可调形变笔刷范围、拉扯力度和边缘柔和度。
- 摇晃手机有两种模式：「选区」（只晃涂选区的部分）和「固定底部」（可自选底部多少比例不动，上半身甩，用力晃可以甩出原图范围）。
- 单击桌宠出现边框，可拖动、缩放；长按进入编辑页。
- UI 颜色跟随 SillyTavern 当前主题变量。

## 安装

在 Termux 中执行：

```bash
cd ~/SillyTavern/data/default-user/extensions
git clone https://github.com/1614130601zjs-del/duangpet.git
```

刷新或重启 SillyTavern 后即可使用「小小桌宠」悬浮球。

## 操作

1. 点击悬浮球打开面板，选择 PNG、WebP 或 JPG。
2. 使用「涂抹选区」把允许互动的部位涂成半透明粉色。
3. 使用「擦除选区」修正范围；「清空选区」会清除全部互动区域。
4. 切换「互动预览」可在编辑舞台中测试；点击「放出桌宠」可将角色放到独立悬浮窗。
5. 在悬浮窗中直接触摸并拖动选区内的角色；拖动顶部把手可移动悬浮窗，点击「收起」返回编辑。
6. 选区、图片和悬浮球位置会保存在本地；松手后形变自动回弹。

## 技术来源

局部 WebGL 网格形变、高斯权重衰减与弹簧回弹，参考作者自己的 [duangduang](https://github.com/1614130601zjs-del/duangduang) 果冻引擎。小小桌宠独立运行，不依赖拾帧，也不会读取或修改聊天消息中的图片。
